# movies_api

Проект для управления базой данных фильмов.

## Основные возможности приложения

Можно добавлять новые фильмы, редактировать информацию о существующих и удалять их. Есть сортировка и фильтрация 

## Технологический стек

- Python 3.12 - язык программирования
- FastAPI - современный веб-фреймворк для создания быстрых API.
- SQLite - локальная база данных.
- SQLAlchemy - для асинхронной работы с базой данных.
- Alembic - для миграций базы данных.
- Pydantic - библиотека для валидации данных.
- Uvicorn - сервер для запуска приложения.

## Быстрый старт

```
2. Установка зависимостей
```

3. Применение миграций

4. Запуск приложения через uvicorn

## Основные эндпоинты
- GET /   проверка сервера.
- GET /movies - получить список фильмов.
- GET /movies/{movie_id} - получить по ID.
- POST /movies - добавить новый фильм.
- PUT /movies/{movie_id} - обновить данные фильма.
- DELETE /movies/{movie_id} - удалить фильм.

## Фильтрация и сортировка

- year_min - по минимальному году выпуска.
- year_max - по максимальному году выпуска.
- min_rating - по минимальному рейтингу.
- order_by - сортировка по одному из столбцов (title, year, rating) и направление.
- limit - количество записей.
- offset - смещение.

## Модель данных

- id - уникальный идентификатор, int.
- title - название фильма, str.
- genre - жанр фильма, str.
- rating - рейтинг фильма, float.
- year - год выпуска, int.

## Ограничения базы данных

- `check_movie_rating_range` - рейтинг фильма должен быть от 0 до 10.
- `check_movie_year_1888` - год выпуска фильма не может быть меньше 1888.
- Поля `title`, `genre`, `rating` и `year` являются обязательными их нельзя оставить пустыми.
